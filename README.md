# Riwaz Acharya Portfolio

A React + Tailwind CSS portfolio for Riwaz Acharya, built around a restrained dark/cyan visual system with an interactive 3D background.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
